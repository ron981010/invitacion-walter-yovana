# Invitación de boda · Walter y Yovana

Adaptación de la plantilla marfil dorada para el 7 de noviembre de 2026 en Huancayo.

## Enlaces

- Invitación: https://walter-yovana-boda-2026.vercel.app/
- Generador: https://walter-yovana-boda-2026.vercel.app/pases.html

## Contenido

Datos de la pareja en `app/wedding.ts`. Diseño e íconos originales conservados; sobre personalizado mediante los parámetros `n` (nombre) y `p` (pases), música de YouTube, itinerario, fotos y confirmación por WhatsApp.

Paleta de referencia azul empolvado, rosa y marfil. Fotografías optimizadas para la invitación.

## Desarrollo

`npm install`, `npm run dev`, `npm run lint`, `npm run build`.

## Publicación

Proyecto independiente en Vercel. `npm run generate:og` actualiza la imagen de compartir.

Este repositorio contiene la versión original. La versión 2 se mantiene independiente. Se excluyen credenciales, configuraciones privadas de despliegue, dependencias instaladas y archivos internos de trabajo.
